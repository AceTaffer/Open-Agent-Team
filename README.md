# Open Agent Team（OAT）· v1.6.0

一个本机的 AI 多智能体工作站：统一管理你自己的各种 AI API，用"团队"的方式让多个 AI 角色协作完成工程/写作/设计任务；v1.1.0 起支持**手机端互联**（手机浏览器接入电脑端，远程监控与操控团队任务）。

- 作者：**Acct** · 特别感谢：**YY程** · AI 开发协作：**deepseek-v4.1-flash** · 邮箱：577940959@qq.com
- 开源免费；本软件为开源软件，可自由使用、学习、修改与分发（分发时请保留作者声明）

## 核心能力
- **API 仓库 / 余额中心**：DeepSeek / OpenAI / Claude / 百炼 / 智谱 / MiniMax / Grok / Gemini / OpenCode Zen / OpenRouter / Kimi / 中转站 / 本地模型等；Key 本机 AES-256-GCM 加密
- **多智能体团队**：队长规划 → 策划/美术/程序/测试/写手/校对等角色协作；返工-复审自动循环；每角色独立权限与工具次数；推理等级滑块
- **工具协议**：读写文件、执行命令、联网搜索、插件调用、凭据保险箱 API、出图/出视频
- **团队预设**：游戏开发 / 软件研发 / 视频制作 / 图片处理 / 文件整理 / 小说写作 + 自定义预设
- **角色长期记忆**：团队任务写入各角色记忆；角色对话自动附带"团队会话档案 + 工作区快照"，减少重复翻文件、提升缓存命中
- **.oat 常驻项目档案（v1.2.0 新增）**：任务收尾自动写入 `工作区/.oat/PROJECT.md`（任务/产物/状态），新会话自动读取——不翻文件也记得项目历史
- **自动续跑 + 验收证据门（v1.2.0 新增）**：完成后自动继续未完成项（0-5 轮，写「【全部完成】」即止）；返工与汇总强制附证据，「无证据不算完成」
- **定时任务 / 心跳（v1.3.0 新增）**：设置页创建「每隔 N 分钟 / 每天 HH:MM」自动任务，无人值守跑完整团队流程；失败自愈重试、连续 3 次自动停用
- **首启向导 + PWA（v1.3.0 新增）**：三步上手（加 API → 选预设 → 示例任务）；手机浏览器可「添加到主屏幕」
- **本地知识库 RAG（v1.4.0 新增）**：自动索引工作区 md/txt/PDF 等文档（`.oat/index.json`），对话与团队步骤自动检索注入；AI 可用 `kb_search` 主动查；零依赖 BM25 + 中文二元分词，纯本机
- **短视频流水线（v1.5.0 新增）**：7 角色团队（导演/编剧/视频美术/配音师/配乐师/剪辑合成/质检）从需求到成片全自动——图生视频、云端配音、BGM、转场、字幕、响度标准化、黑屏检测、质检返工循环；15 秒竖屏成片实测跑通
- **本地声音引擎（v1.6.0 新增）**：接入 VoiceStudio（开源本地语音工作室）——离线配音 + 少样本音色克隆（`clone_voice`）；设置页一键下载/运行安装包、检测连接，声音数据不出本机
- **手机端互联（v1.1.0 新增）**：见下

## 手机端互联（v1.1.0）
- **配对**：电脑端「设置 → 手机连接」→ 开启局域网监听（需重启）→ 生成配对码：手机与电脑同一 Wi-Fi 时，用手机系统相机**扫码自动配对**，或手机浏览器打开提示地址输入 **6 位配对码**
- **设备安全**：设备令牌 + 权限档（只读 / 可操作 / 可批准 / 可配置），可命名、改权限、撤销（立即失效）；远程操作记录于 `data/audit.jsonl`
- **手机端能力**：走电脑代理对话（API Key 不出电脑）、远程监控与控制团队任务（暂停/继续/终止/中途指令/单角色对话）、批准权限申请、回答 AI 提问
- **断线不暂停**：手机切后台/断网不打断电脑端任务；任务事件落盘，重连后完整回放
- **跨设备同步**：事件流广播数据变更，多设备自动刷新/提示
- **异地使用（可选）**：EasyTier 一键引导（官方下载 + 独立进程，需管理员授权）；手机安装 EasyTier 官方 Android 客户端加入同一网络后访问 `http://本机虚拟IP:3410`

## 快速开始（电脑端）
1. 安装 Node.js（18+，推荐 24），双击 `启动工作站.bat`（默认端口 **3410**）
2. 或用「启动桌面版.bat」以独立窗口运行
3. 详细说明见《使用说明.txt》
