# ★ AI 智能体工作站

统一管理你手上所有 AI API（DeepSeek、阿里云百炼、OpenCode Go、OpenRouter、硅基流动、Kimi、中转站、本地模型），
随时看清**每个 API 是谁、还剩多少钱**，并让智能体自己从仓库里找接口调用。

## 快速开始

双击 **`启动工作站.bat`**（或在本目录执行 `node server.mjs`），浏览器会自动打开
`http://127.0.0.1:3410`。

首次使用：
1. 点右上角 **「+ 添加 API」**，选择厂商模板（自动填好 BaseURL 和常用模型），粘贴你的 API Key；
2. 保存后点「测试」验证连通性；
3. 余额接口支持的厂商会直接显示剩余金额（DeepSeek / OpenRouter / Kimi / OpenCode Go 订阅额度）；
   没有余额接口的（百炼、硅基流动等）显示「连通正常（该厂商无余额接口）」；
4. 左栏点选一个 API，在「对话」页输入指令即可使用（流式输出）。

## 目录结构

```
E:\集合工作站\
├── server.mjs        ← 后端（零依赖，Node 内置模块）
├── web\              ← 前端（原生 JS，无需构建）
│   ├── index.html
│   ├── app.js
│   └── style.css
├── data\             ← 你的数据（自动生成）
│   ├── providers.json    API 配置（不含明文密钥）
│   ├── secrets.json      加密后的 API Key（AES-256-GCM）
│   └── .key              本机加密密钥（自动生成）
├── 启动工作站.bat
└── package.json
```

## 安全说明

- 服务只监听 `127.0.0.1`，不对局域网/外网开放；
- API Key 用 AES-256-GCM 加密后保存，界面只显示掩码（如 `sk-••••abcd`）；
- 删除 API 会连同密钥一起清除；
- 不要把这个文件夹连同 `data\.key` 一起发给别人。

## 常见问题

- **端口被占用**：`set PORT=3411 && node server.mjs`
- **余额查不到**：确认 Key 正确；部分厂商（百炼、硅基流动）本身没有"用 Key 查余额"的公开接口，
  属于正常现象，可点「测试」验证 Key 是否可用。
- **本地模型**：选「本地智能体」模板，BaseURL 填 Ollama（`http://127.0.0.1:11434/v1`）
  或 LM Studio，Key 留空即可。
