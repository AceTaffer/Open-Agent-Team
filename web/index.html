Agent 工作方式 / 权限

 
 
查看=只读；修改=工作区内读写；受限=工作区外可读、区内可写；完全=允许敏感操作并减少确认步骤。

 
除「完全权限」外，AI 的写文件/执行命令等操作会逐项弹出确认，可选择「允许一次 / 本会话全部允许 / 拒绝」。可在对话工具栏单独调整当前会话权限。

 
  
对 DeepSeek V4 系列等推理模型生效：思考过长会耗尽输出预算，导致「只思考不回答」并大量消耗 token，推荐「低」。

EasyTier 异地组网（可选）

  
让手机在任意网络（流量/异地 Wi-Fi）也能连回本机：电脑与手机都加入同一个 EasyTier 网络即可（P2P 直连；共享节点仅作引荐与兜底）。启动需要管理员权限，电脑会弹 UAC 授权框。

  

  
  
  
  

  

  
  
  
  
  

  
手机端：安装 EasyTier 官方 Android 客户端并加入相同网络名/密码，然后手机浏览器访问「http://本机虚拟IP:3411」即可（与局域网访问用法相同）。

  
EasyTier 为 LGPL-3.0 开源项目（github.com/EasyTier/EasyTier）。本软件仅从官方 Release 下载并以独立进程方式调用，不修改其代码；详见《第三方声明与许可》。

项目档案（.oat）

  
团队任务收尾会自动把「任务 / 步骤 / 产物 / 状态」写入当前工作区的 .oat/PROJECT.md；之后新会话与角色对话会自动读取，记得项目历史、无需翻文件。档案属于项目本身，可随项目复制/迁移。

  

  
  
  
  

  

  

  
定时任务（心跳）

  
无人值守：按「每隔 N 分钟」或「每天 HH:MM」自动给团队下达任务；任务照常写入团队会话与 .oat 项目档案。失败 5 分钟后自动重试，连续 3 次失败自动停用（避免无人时反复烧钱）。

  

  
  
  
  

  

  

  
本地知识库（RAG）

  
给当前工作区的文档（md / txt / PDF 等）建本地索引：角色对话与团队步骤会自动检索并引用相关内容，AI 也可用 kb_search 工具主动查。索引保存在 工作区/.oat/index.json（随项目迁移），纯本机、无外部服务；PDF 抽取为尽力而为（扫描版不支持）。

媒体引擎（短视频）

  
ffmpeg 用于视频合成（转场/混音/字幕烧录）与媒体探测；TTS 用于配音；背景音乐优先使用工作区 bgm/ 目录里的音乐，没有时可用内置合成氛围乐。团队预设「短视频制作组」使用本卡片配置。

本地声音引擎（均为可选，均在电脑端）：VoiceStudio——少样本音色克隆、离线配音（首次合成下载模型约 2.3GB）；Qwen-TTS（进阶可选）——连接 licyk Qwen TTS WebUI 的本地 API（默认 127.0.0.1:7860，需自行准备整合包与模型；OAT 只做 API 调用，不随包分发引擎与模型）。
