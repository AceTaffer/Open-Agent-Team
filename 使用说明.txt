 Open Agent Team v1.1.0 · 使用说明
════════════════════════════════════════════════════════════

【这是什么】
一个本机的 AI 多智能体工作站：统一管理你自己的各种 AI API，用"团队"方式让多个
AI 角色协作干活；v1.1.0 起支持手机端互联（手机远程监控/操控团队任务）。

【电脑端启动】
  1) 安装 Node.js（18+，推荐 24）：https://nodejs.org
  2) 双击「启动工作站.bat」→ 浏览器自动打开 http://127.0.0.1:3410
  3) 也可双击「启动桌面版.bat」使用独立窗口

【手机连接（同一 Wi-Fi）】
  1) 设置 → 手机连接 → 勾选「局域网监听」→ 点「重启服务使监听生效」
  2) 点「生成配对码」：
     · 扫码：用手机系统相机扫二维码，自动配对并进入手机端页面
     · 或：手机浏览器打开页面提示的地址，输入 6 位配对码（5 分钟有效）
  3) 配对成功后即可：
     · 手机端对话（AI 调用走电脑代理，API Key 不会同步到手机）
     · 查看/控制团队任务：暂停 / 继续 / 终止 / 中途指令 / 与单个角色对话
     · 批准 AI 的权限申请、回答 AI 提问
     · 断线不暂停：手机切后台或断网，电脑端任务照常运行，重连后完整回放
  4) 设备管理：设置 → 手机连接，可命名/改权限档/撤销设备（撤销后立即失效）

【手机连不上？】
  · 确认手机与电脑在同一 Wi-Fi（或已用 EasyTier 组网）
  · 检查 Windows 防火墙：设置 → 手机连接 →「手机连不上？防火墙设置」，
    按提示允许 Node.js 入站（专用网络）

【异地使用（可选）：EasyTier 组网】
  1) 设置 → 手机连接 → EasyTier 区：点「一键下载安装」（官方 Release）
  2) 填写网络名称 / 网络密码 / 本机虚拟 IP（默认 10.126.126.1）
  3) 点「启动组网」→ 在电脑上确认管理员授权（UAC 弹窗）
  4) 手机安装 EasyTier 官方 Android 客户端，加入相同网络名/密码，
     手机浏览器访问 http://本机虚拟IP:3410

【主要功能速览】
  · API 仓库 / 余额：多厂商模板、Key 本机加密、余额与订阅额度
  · 对话：工具调用（读写文件/执行命令/联网/插件）、思考折叠、推理等级滑块
    （可拖动 关闭/低/默认/高/最大，越高动画越炫）、环形上下文占用指示
    （悬停看 费用/使用率/Token/缓存命中）
  · 团队任务：队长规划→角色执行→自动返工-复审；每角色独立权限与工具次数；
    角色长期记忆（做完不失忆，减少重复翻文件）；角色卡片显示费用/使用率/Token/缓存命中
  · 团队预设：游戏开发 / 软件研发 / 视频制作 / 图片处理 / 文件整理 / 小说写作 / 自定义
  · 凭据保险箱：任意 HTTP API 加密保存，AI 可直接调用（密钥自动携带）
  · 热更新：设置页一键检查/下载更新（只覆盖程序文件，数据保留）

【隐私与安全】
  · 所有数据只保存在本机 data / 工作区目录，无遥测；Key 使用 AES-256-GCM 加密
  · 默认仅监听 127.0.0.1；开启手机连接后通过令牌+权限档控制，可随时撤销设备
  · 远程操作有审计日志：data/audit.jsonl
