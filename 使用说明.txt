  Open Agent Team v1.8.0 · 使用说明

【这是什么】
一个本机的 AI 多智能体工作站：统一管理你自己的各种 AI API，用"团队"方式让多个
AI 角色协作干活；v1.1.0 起支持手机端互联（手机远程监控/操控团队任务）。

【v1.8.0 新增 · Qwen-TTS 本地 API（进阶可选，仅电脑端）】
  · 支持连接 licyk「Qwen TTS WebUI」整合包的本地 REST API（/qwenapi/v1，
    默认 127.0.0.1:7860）：设置 → 媒体引擎 → 声音后端选「本地 Qwen-TTS」，
    填地址后点「检测 Qwen」
  · 配音走本地合成：generate_speech 可用 WebUI 预设音色；clone_voice 可把
    一段参考音频登记为音色（之后 voice 传音色名即可）
  · 注意：OAT 只做 API 调用，不随包提供引擎与模型——请自行准备整合包
    （解压约 4.65GB 含 Python/CUDA 环境）；首次合成会自动下载模型
    （0.6B 克隆模型约 1.8GB；显存建议 ≥4GB，16GB 内存机器无压力）
  · 该通路为示例性开放接口，未做深度打磨；欢迎社区用户按需扩展
    （训练/微调等）；手机端不包含本功能
  · 最新手机端 APK 见 GitHub Release 附件（v1.8.0）

【v1.7.0 新增 · Android 手机端（APK）】
  · 下载：GitHub Release 附件 OAT手机端_v1.7.0.apk（arm64，Android 8.0+）
  · 两种模式（顶栏一键切换）：
    - 远程模式：手机连电脑（设置里填电脑地址），界面与电脑端实时同步；
    - 本地模式：引擎内嵌在手机里（JNI），离线可聊天/团队任务/文件操作，
      数据存手机应用私有目录，与电脑端互不影响
  · 手机端热更新：本地模式下"检查更新→一键更新"直接更新手机内的引擎文件
    （重启 App 生效；手机数据不受影响）
  · 手机 UI 简约化：功能收纳进左侧抽屉（≡）；团队页单行角色条（可单独查看/总览）；
    对话与任务输入框上方有「推理等级」可折叠条；支持上传图片/文件与新建文件
  · 双端都能干活：电脑与手机各自可下达任务、写文件、跑项目

【v1.6.0 新增 · 本地声音引擎（VoiceStudio）】
  · 设置 → 媒体引擎：一键「下载安装包 / 运行安装包 / 检测连接」；
    「声音后端」切到「本地 VoiceStudio」后，配音全部在本机完成（离线、免费）
  · 少样本音色克隆：给一段 10 秒~2 分钟的干净人声样本，配音师可用
    clone_voice 生成专属音色；克隆记录保存在本机，配音时直接引用
  · 安装包下载自带国内镜像回退与 sha256 校验；首次合成会下载语音
    模型（约 2.3GB，仅第一次）
  · 许可提示：VoiceStudio 为 AGPL-3.0 开源项目（独立进程调用），
    克隆音色须获得声音权利人同意（详见《第三方声明与许可》）
  · 另：设置页整体布局对齐统一（控件高度/行距/按钮一致，同排卡片等高）

【v1.5.0 新增 · 短视频流水线】
  · 团队预设「短视频制作组」：导演 / 编剧 / 视频美术 / 配音师 / 配乐师 /
    剪辑合成 / 质检——一句话需求，全自动产出带配音、字幕、音乐、转场
    与动画效果的成片（竖屏 9:16 / 横屏 16:9，按任务选择）
  · 媒体工具链：generate_speech（云端 TTS 配音，百炼 qwen-tts）、
    generate_music（优先用工作区 bgm/ 目录音乐，也可内置合成氛围乐）、
    make_subtitles（ASS+SRT，时间轴与配音对齐）、compose_video（一键合成：
    归一化/转场/混音/烧字幕/响度标准化）、media_probe（时长/轨道/响度/
    黑屏检测，质检证据）
  · generate_video 支持图生视频（关键帧→视频，失败自动回退文生视频）、
    批量多镜、进度可视
  · ffmpeg 首次使用时自动下载并校验（约 100MB；也可手动放 tools/ 目录）
  · 设置页「媒体引擎」卡片：ffmpeg 状态 / 声音后端 / TTS 模型与音色
  · 实测：15 秒竖屏成片（3 镜、中文配音、ASS 字幕、氛围 BGM、-16 LUFS）

【v1.4.0 新增】
  · 本地知识库（RAG）：自动给工作区文档（md / txt / PDF 等）建索引
    （存 工作区/.oat/index.json）；角色对话与团队步骤自动检索并引用最相关
    片段；AI 也可用 kb_search 工具主动查。纯本机、零依赖，无需 Embedding API
  · 设置页「本地知识库」卡片：查看索引状态、重建索引、检索测试、
    关闭/开启自动注入；索引超过 30 分钟自动增量刷新
  · 说明：PDF 为尽力而为的文本抽取（扫描版/加密 PDF 不支持）

【v1.3.0 新增】
  · 定时任务/心跳：设置页创建「每隔 N 分钟」或「每天 HH:MM」自动任务，
    到点自动给团队下达指令并跑完整流程，结果写入会话与 .oat 档案；
    失败 5 分钟后自动重试，连续 3 次失败自动停用（无人值守安全阀）
  · 首启向导：未配置 API 时对话页顶部三步引导 + 示例任务一键填入
  · PWA：手机浏览器「添加到主屏幕」当 App 用（Android 原生壳规划中）

【v1.2.0 新增】
  · .oat 项目档案：团队任务收尾自动写入 工作区/.oat/PROJECT.md
    （任务/步骤/产物/状态），角色对话与团队步骤自动读取——新会话不翻文件
    也能记得项目历史；设置页可「查看/编辑/清空」
  · 自动续跑：团队任务栏可选 0-5 次；完成后自动继续未完成项，
    汇总里写出「【全部完成】」即停（任务照常落盘，可随时接回）
  · 验收证据门：返工与最终汇总强制附证据（文件读回片段/命令原文与输出），
    无法验证必须标注「未验证」；新增内置技能「验收证据规范」
  · 后台系统通知（任务完成/待授权/待回答；http 下退化为标题闪烁）
    + SSE 断线自动重连横幅 + 手机连接页 IPv6 地址显示与复制
  · 安全加固：配对码失败限速、调试工具命令注入修复、请求体上限、
    保险箱「清除保护」仅限本机、危险命令黑名单扩充等

【电脑端启动】
  1) 安装 Node.js（18+，推荐 24）：https://nodejs.org
  2) 双击「启动工作站.bat」→ 浏览器自动打开 http://127.0.0.1:3410
  3) 也可双击「启动桌面版.bat」使用独立窗口

【手机连接（同一 Wi-Fi）】
  1) 设置 → 手机连接 → 勾选「局域网监听」→ 点「重启服务使监听生效」
  2) 点「生成配对码」：
     · 扫码：用手机系统相机扫二维码，自动配对并进入手机端页面
     · 或：手机浏览器打开页面提示的地址，输入 6 位配对码（5 分钟有效）
  3) 配对成功后即可：
     · 手机端对话（AI 调用走电脑代理，API Key 不会同步到手机）
     · 查看/控制团队任务：暂停 / 继续 / 终止 / 中途指令 / 与单个角色对话
     · 批准 AI 的权限申请、回答 AI 提问
     · 断线不暂停：手机切后台或断网，电脑端任务照常运行，重连后完整回放
  4) 设备管理：设置 → 手机连接，可命名/改权限档/撤销设备（撤销后立即失效）

【手机连不上？】
  · 确认手机与电脑在同一 Wi-Fi（或已用 EasyTier 组网）
  · 检查 Windows 防火墙：设置 → 手机连接 →「手机连不上？防火墙设置」，
    按提示允许 Node.js 入站（专用网络）

【异地使用（可选）：EasyTier 组网】
  1) 设置 → 手机连接 → EasyTier 区：点「一键下载安装」（官方 Release）
  2) 填写网络名称 / 网络密码 / 本机虚拟 IP（默认 10.126.126.1）
  3) 点「启动组网」→ 在电脑上确认管理员授权（UAC 弹窗）
  4) 手机安装 EasyTier 官方 Android 客户端，加入相同网络名/密码，
     手机浏览器访问 http://本机虚拟IP:3410

【主要功能速览】
  · API 仓库 / 余额：多厂商模板、Key 本机加密、余额与订阅额度
  · 对话：工具调用（读写文件/执行命令/联网/插件）、思考折叠、推理等级滑块
    （可拖动 关闭/低/默认/高/最大，越高动画越炫）、环形上下文占用指示
    （悬停看 费用/使用率/Token/缓存命中）
  · 团队任务：队长规划→角色执行→自动返工-复审；每角色独立权限与工具次数；
    角色长期记忆（做完不失忆，减少重复翻文件）；角色卡片显示费用/使用率/Token/缓存命中
  · 团队预设：游戏开发 / 软件研发 / 视频制作 / 图片处理 / 文件整理 / 小说写作 /
    角色扮演推演（主持GM/世界观架构师/角色设计师/群像扮演/推演编剧/设定校对，
    产出世界书 + V2 兼容角色卡 + 群像场景 + 推演纪要）/ 自定义
  · 凭据保险箱：任意 HTTP API 加密保存，AI 可直接调用（密钥自动携带）
  · 热更新：设置页一键检查/下载更新（只覆盖程序文件，数据保留）

【隐私与安全】
  · 所有数据只保存在本机 data / 工作区目录，无遥测；Key 使用 AES-256-GCM 加密
  · 默认仅监听 127.0.0.1；开启手机连接后通过令牌+权限档控制，可随时撤销设备
  · 远程操作有审计日志：data/audit.jsonl
